## How I approach an engineering challenge

```text
Understand the problem
       ↓
Map constraints, users, and failure modes
       ↓
Sketch architecture and evaluate trade-offs
       ↓
Prototype quickly (AI-assisted where useful)
       ↓
Implement in small, testable increments
       ↓
Review • Test • Observe • Iterate
```

**AI is part of the workflow, not the source of truth.** I use it to compress feedback loops while keeping requirements, architecture decisions, code quality, security, and production outcomes under deliberate engineering control.
