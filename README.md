I'm an iOS engineer experienced in building and modernizing mobile applications across **messaging and VoIP, government field operations, e-commerce, telecommunications, healthcare, and sensor-driven utilities**.

I work across the full delivery lifecycle: translating complex requirements into maintainable architectures, implementing responsive interfaces and dependable data flows, diagnosing production issues, and shipping updates to the App Store.
